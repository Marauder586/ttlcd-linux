    🔔 Alert Thresholds

    Automatically fire alerts when CPU or temperature exceeds these limits. Set to 0 to disable. Alerts are shown on the panel and forwarded to ntfy.sh if configured.

    🔔 ntfy.sh Push Notifications

    Receive alert notifications on your phone or desktop. When configured, any threshold breach, service failure, or alert will be POSTed to your ntfy.sh topic.

    🐱 Pet Cat

    A pixel-art cat that naps, licks its paw, stretches and plays with a ball. Changes apply immediately.

    💤 Screensaver / Idle Timeout

    Automatically switch to a screensaver mode (e.g. Matrix Rain or Idle) after a period of inactivity. Any API call wakes the display and restores the previous mode.

    🔐 API Authentication

    Set a Bearer token to restrict API access. Once set, all API requests must include Authorization: Bearer <key>. The key is not persisted — it clears on daemon restart.

    🌙 Night Mode

    Automatically switch to a quieter mode between set hours. Useful for dimming or switching to a minimal clock overnight.
